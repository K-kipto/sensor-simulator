# Temperature Sensor Simulator

A small Python learning project connected to my studies in Microprocessor
Technology and Instrumentation. It simulates a temperature sensor taking
readings and summarises them.

**Note:** This starter was created with AI assistance as a learning exercise.
I am studying the code and extending it myself.

## What it does
- Simulates 10 temperature readings
- Shows each reading in Celsius and Fahrenheit
- Flags readings above a warning limit
- Prints the minimum, maximum and average

## How to run
```
python sensor_simulator.py
```

## What I am learning
- Functions, loops and list comprehensions
- Using the `random` module
- Basic data summaries (min, max, average)
